# Simple Light Bulb Project

Hi! This is a small project I made to practice using JavaScript with HTML images. It is a simple web page with a light bulb image and a button. When you click the button, the bulb turns on, and when you click it again, the bulb turns off.

# How it works
Inside the HTML, I have a normal bulb image and a button that says Turn ON. In the JavaScript code, I added a click event listener to the button. When someone clicks the button, the code checks the current image. If the image is the off bulb, it changes it to the on bulb image and updates the button text to Turn OFF. If the bulb is already on, it switches it back to the off bulb image and changes the text back to Turn ON.

# What I learned in this project
I learned how to select HTML elements in JavaScript using getElementById. I also practiced using getAttribute and setAttribute to change the source path of an image dynamically. Lastly, I learned how to use a simple if-else condition to toggle between two states.

# How to run it
To see it working, you need to have two images named bulb.jpeg (off bulb) and bulbon.jpeg (on bulb) in the same folder as the index.html file. Then, just double-click the index.html file to open it in your browser.
